# Chrome Remote Hangul

Chrome 원격 데스크톱으로 Mac에 접속할 때, \
물리 키보드의 한/영키로 **한국어 두벌식 ↔ ABC**를 전환하는 Hammerspoon 설정입니다.

물리 키보드를 통해 태블릿으로 맥 연결해서 쓰다가 한/영 전환이 안 돼서 Codex 시켜 만들었습니다.

## 주요 기능

- 물리 키보드의 한/영 키를 누르면 원격 접속한 맥에서 한/영 전환이 되도록 합니다.
- Mac 상단 메뉴 막대의 `한/영` 버튼을 클릭하면 한/영 전환이 됩니다.


## 실행 전 유의 사항

- `install.command`를 실행하면 **Hammerspoon이 없는 Mac에는 앱을 자동으로 다운로드하여 설치**합니다.
  - 이미 설치된 Hammerspoon은 그대로 사용합니다.
- 설정 파일을 배치한 뒤 한/영 키 등록을 시작합니다. 
  - 한/영 키 외에도 다른 키를 등록해 사용할 수 있습니다.
- 손쉬운 사용 모드 요청 승인이 필요합니다.


## `tl;dr` 실행 방법 다섯 줄 요약

- 크롬 원격 데스크탑이 실행되어있는 것을 가정합니다.
- 크롬 원격 데스크탑에서 키 매핑을 통해 `AltRight`를 `Lang1`으로 매핑하세요.
- 파일들을 다운로드 하세요.
- `install.command`를 실행하세요.
- 그 이후엔 시키는 대로 합니다.


## 준비 사항

- 접속 대상 Mac과 Chrome 원격 데스크톱 연결
- 접속 기기에 연결된 물리 키보드
- Mac 입력 소스의 **ABC**, **한국어 - 두벌식**
- 최초 Hammerspoon 다운로드를 위한 인터넷 연결

설치에는 macOS 기본 도구를 사용합니다. Homebrew, Xcode, Python은 필요하지 않습니다.

## 1. Chrome 원격에서 키를 미리 매핑하기 — 권장

**접속하는 기기 쪽 Chrome 원격 데스크톱의 키 매핑을 먼저 설정하는 것을 권장합니다.** 한/영키가 `Right Alt`로 인식된다면, 해당 키를 `Lang1` 등 Mac에 전달되는 키로 매핑한 뒤 등록하세요.

| 항목 | 권장 예시 |
| --- | --- |
| 원래 키 | `Right Alt` — 실제 물리 한/영키에 해당하는 입력 |
| 대상 키 | `Lang1` |

```text
물리 한/영키 → Chrome 원격의 Right Alt → Lang1 → Mac에서 한/영 전환
```

원래 키의 표시 이름과 키 매핑 화면은 접속 기기·키보드에 따라 다를 수 있습니다. 실제 한/영키를 눌렀을 때 인식되는 항목을 선택하세요.

갤럭시 + Chrome 원격 데스크톱 앱에서 `Lang1`이 Mac의 **키 코드 104 (`kana`)**로 전달되어 동작하는 것을 확인했습니다. 다른 대상 키를 사용하더라도 Mac까지 전달되면 아래 등록 과정으로 지정할 수 있습니다.

> 설치 스크립트는 접속 기기의 Chrome 원격 키 매핑을 변경하지 않습니다. 이 설정은 접속 기기에서 직접 저장하세요.

## 2. Mac에서 설치 스크립트 실행하기

1. 배포 ZIP을 **모두 압축 해제**합니다.
2. `install.command`와 세 개의 `.lua` 파일을 같은 폴더에 둡니다.
3. **접속 대상 Mac에서** `install.command`를 더블 클릭합니다.

터미널에서 실행하려면 `/bin/bash`와 공백을 입력한 다음, `install.command` 파일을 터미널 창에 끌어 넣고 Enter를 누르세요. 더블 클릭 실행이 제한되거나 실행 권한이 없다는 메시지가 나올 때도 이 방법을 사용할 수 있습니다.

### 자동으로 처리하는 작업

- Hammerspoon이 없으면 [공식 GitHub 배포본](https://github.com/Hammerspoon/hammerspoon/releases/latest)을 다운로드하고, 앱 서명 및 macOS 실행 검증 후 설치합니다.
- 기본 설치 위치는 `/Applications/Hammerspoon.app`이며, 해당 폴더에 쓸 수 없으면 `~/Applications/Hammerspoon.app`을 사용합니다.
- `~/.hammerspoon`에 설정 파일을 배치하고, 기존 `init.lua`에 모듈을 불러오는 짧은 구문을 연결합니다.
- 변경 전 설정 파일을 `~/.hammerspoon/backups/chrome-remote-lang1/`에 백업합니다.
- Hammerspoon을 실행하거나 다시 실행하고, 한/영키 등록을 요청합니다.

### 실행 시 주의할 점

- **로그인한 Mac 사용자 계정으로 실행하세요. `sudo`는 사용하지 마세요.**
- ZIP 안에서 실행하거나 `install.command`만 따로 복사하지 말고, 필요한 파일을 모두 압축 해제하세요.
- 설정을 적용하면서 실행 중인 Hammerspoon을 다시 시작하므로, Hammerspoon의 다른 자동화도 잠시 중단될 수 있습니다.
- 기존 `init.lua` 본문은 유지합니다. 이전 한/영 처리 코드가 직접 들어 있는 경우에는 중복 전환 방지를 위해 설치를 중단할 수 있습니다.
- 다운로드나 서명 검증에 실패하면 설치를 중단합니다. 표시된 오류를 확인한 후 다시 실행하세요.

## 3. 권한과 입력 소스 설정하기

다음 작업은 사용자가 직접 완료해야 합니다.

1. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Hammerspoon을 허용합니다.
2. 처음 권한을 허용했다면 **Hammerspoon을 완전히 종료한 뒤 다시 실행**합니다. 대기 중인 키 등록 요청이 이어집니다.
3. **시스템 설정 → 키보드 → 입력 소스**에 **ABC**와 **한국어 - 두벌식**을 추가합니다.

재부팅 후에도 사용하려면 Hammerspoon Preferences의 **Launch Hammerspoon at login**을 켜세요. 한/영 전환은 Hammerspoon이 실행 중일 때 동작합니다.

## 4. 한/영키 두 번 입력하여 등록하기

**실제로 사용할 원격 기기의 물리 키보드로** 진행하세요.

1. Mac 원격 화면의 **원격 한/영키 등록** 창에서 **입력 시작**을 클릭합니다.
2. 물리 한/영키를 **한 번 눌렀다 뗍니다**.
3. 감지한 키 이름과 코드를 확인하고 **확인 후 재입력**을 클릭합니다.
4. **같은 한/영키를 한 번 더 눌렀다 뗍니다**.
5. 두 입력이 일치하면 저장하고 **한/영키 등록 완료**를 표시합니다.

각 입력 대기 시간은 **60초**입니다. 길게 눌러 발생하는 반복 입력은 두 번째 입력으로 세지 않습니다. 입력 중에는 다른 키를 함께 누르지 마세요.

입력 대기 중에는 `Esc` 또는 메뉴의 **등록 취소**를 클릭하고, 확인 창에서는 **취소**를 클릭해 중단할 수 있습니다. 취소하거나 시간이 초과되면 기존 매핑을 유지합니다. 두 입력이 다르면 저장하지 않고 다시 등록할 수 있습니다. 등록 화면이 열려 있는 동안에는 키 매핑에 따른 전환을 잠시 멈춥니다.

일반 키와 `Right Alt` 같은 단독 보조키를 등록할 수 있습니다. 보조키로 등록한 경우 다른 키와 조합해서 누르면 한/영을 전환하지 않습니다. `Caps Lock`은 지원하지 않으며, `Esc`는 등록 취소에 사용합니다.

## 사용 방법

| 동작 | 결과 |
| --- | --- |
| 등록한 물리 한/영키를 눌렀다 떼기 | 한국어 두벌식 ↔ ABC 전환 |
| **Mac 상단 메뉴 막대의 `한/영` 버튼 클릭** | **키보드 입력 없이 한/영 전환** |
| Option을 누른 채 `한/영` 버튼 클릭 | 키 다시 등록 |
| `install.command` 다시 실행 | 설치 상태 확인 및 키 다시 등록 |

등록한 매핑은 Hammerspoon을 다시 실행해도 유지됩니다. 새 등록 없이 설치·업데이트만 하려면 `--skip-registration` 옵션을 사용하세요.

등록값은 Hammerspoon 환경설정의 `crdHangulRegisteredKeyV1` 항목에 저장하며, 일반적인 재설치로 지워지지 않습니다. 저장된 매핑이 없으면 기본값인 `Lang1`(코드 104)을 사용합니다.

## 문제 해결

### 키가 감지되지 않습니다

원격 Mac 화면을 클릭하고 다시 시도하세요. 손쉬운 사용 권한을 확인하고, 암호 입력창을 닫은 일반 화면에서 진행하세요.

Android 또는 Chrome 원격이 Mac에 보내지 않는 키는 이 설정으로 감지할 수 없습니다. 접속 기기의 Chrome 원격 키 매핑을 `Right Alt → Lang1` 등으로 저장한 뒤 다시 등록하세요. **메뉴 막대의 `한/영` 버튼을 클릭하는 방법도 사용할 수 있습니다.**

### 등록은 됐지만 언어가 바뀌지 않습니다

Mac에 **ABC**와 **한국어 - 두벌식**이 모두 추가되어 있는지 확인하세요. 이 설정은 두 입력 소스를 기준으로 동작합니다.

### Mac에 직접 연결된 키보드에서도 동작하나요?

매핑은 Mac 전체에 적용됩니다. 로컬 키보드가 등록한 키와 같은 Mac 키 코드를 보내면 그 키에도 반응합니다.

## 설치 옵션

파일이 있는 폴더에서 다음과 같이 실행합니다.

```bash
/bin/bash ./install.command --help
```

| 옵션 | 동작 |
| --- | --- |
| `--dry-run` | 실제 변경 없이 설치 계획만 표시 |
| `--config-only` | Hammerspoon 앱 다운로드·설치 생략 |
| `--no-launch` | 앱 재실행과 시스템 설정 열기 생략. 키 등록 요청은 다음 Hammerspoon 실행 때 처리 |
| `--skip-registration` | 새 키 등록 없이 설치·업데이트하고 기존 매핑 유지 |
| `--config-dir 절대경로` | 설정 폴더 지정. 기본값은 `~/.hammerspoon` |
| `--app-dir 절대경로` | Hammerspoon 앱 설치 폴더 지정 |
| `--help` | 옵션 안내 표시 |

다른 설정 폴더를 지정했다면 Hammerspoon도 해당 설정 폴더를 사용하도록 구성해야 합니다.
